## 🎯 What You Can Do Inside

Here's a taste of what awaits you:

### 🧠 Neural Network Visualizer
Drag the sliders to adjust weights and biases. Watch how the network's output changes instantly. Try to "teach" it to recognize a simple pattern.

### 🧭 Search Algorithm Explorer
See how a computer finds its way through a maze. Switch between different search strategies (like breadth-first or depth-first) and compare their paths in real time.

### 🤖 Reinforcement Learning Agent
You'll see a little robot learning to navigate a grid. Press "Train" and watch it improve step by step. Change the reward locations and see how the robot adapts.

### 👁️ Vision Lab
Upload a simple image or draw with your mouse. The system will highlight the edges, shapes, and patterns it detects. Adjust the sensitivity to see what changes.

### 🎲 Probability Playground
Flip virtual coins, roll dice thousands of times, and watch the outcomes approach theoretical probabilities. Great for understanding statistics.

### 🧩 Game Tree Arena
Play a simplified version of tic-tac-toe or connect-four against the AI. The game tree is displayed next to the board so you can see every possible move the computer considers.
